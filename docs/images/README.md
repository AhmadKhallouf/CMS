## Tips

- Use **1920×1080** or **1440×900** window size; crop to content if needed.
- Capture **light mode** for storefront; **dark mode** for at least one admin screenshot.
- Remove or blur any real emails, API keys, or card numbers.
- Use PNG for crisp UI text.
